coin-premium은 Upbit(KRW)과 Binance(USDT)의 실시간 체결가, 한국수출입은행 공식 환율을 모아
김치프리미엄을 계산합니다.

김프(%) = (국내 가격 ÷ (해외 가격 × 환율) − 1) × 100

## 제공 기능
- **현재 김프**: 최신 체결가 기준 실시간 계산
- **김프 추이**: 1분 스냅샷을 1m·1h·1d 캔들로 집계

## 공통 규칙
- 시각은 ISO-8601 **UTC** (예: `2026-11-11T05:00:00Z`)
- 금액·김프율은 소수 정밀도를 유지한 숫자
- 에러는 ProblemDetail(RFC 9457) 형식이며 `code`로 구분합니다
