# 004. 체결 시각이 수신 시각보다 미래

- 날짜: 2026-11-05

## 증상
Binance 체결의 `tradedAt`이 collector의 수신 시각보다 늦게 찍힘. 여러 번 재현됨.
```
로그 시각(로컬):  13:35:53.996Z
tradedAt(Binance): 13:35:54.004Z   → 받기 8ms 전에 체결?
```
같은 시점 Upbit은 `tradedAt` → 수신까지 약 130ms로 자연스러움.

## 원인
로컬 Mac 시계와 Binance 서버 시계의 오차(clock skew). 한국–Binance 네트워크 지연을 고려하면 로컬 시계가 상당히 늦은 것으로 추정.

## 영향
5단계에서 "수신 지연 = receivedAt − tradedAt"을 모니터링 지표로 쓸 계획인데, 이 값이 음수가 될 수 있다.

## 대응 계획
- 지연 지표는 절대값보다 평소 대비 추세로 본다
- 음수 값으로 알람이 오작동하지 않도록 처리
- 서버는 NTP 동기화 (K8s 노드 설정 확인)

## 관련: 시간대 표시 혼동
환율 이벤트 `publishedAt`이 `2026-11-04T15:00:00Z`로 하루 전처럼 보였으나, KST로는 `2026-11-05 00:00`으로 정상. 저장은 UTC, 표시할 때만 KST로 변환하는 원칙을 유지한다.

## 배운 점
분산 환경에서 서로 다른 서버의 시각은 그대로 비교할 수 없다.
