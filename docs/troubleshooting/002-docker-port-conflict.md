# 002. Docker Compose 3306·9092 포트 충돌

- 날짜: 2026-11-05

## 증상
`docker compose up` 시 MariaDB·Kafka 포트 바인딩 실패.

## 원인
| 포트 | 이미 사용 중 |
| --- | --- |
| 3306 | Mac에 직접 설치된 MySQL (자동 실행) |
| 9092 | 다른 프로젝트의 Kafka 클러스터 |

## 해결
컨테이너 내부 포트는 유지하고 호스트 포트만 분리.
- MariaDB: `3307:3306`
- Kafka: EXTERNAL 리스너 19092 (포트 매핑·advertised listener·healthcheck 함께 변경)

## 판단
기존 Kafka 클러스터를 공유하지 않고 프로젝트별 독립 환경을 선택했다.
- 공유 시 다른 프로젝트 토픽·컨슈머 그룹과 섞임
- 다른 클러스터를 내리면 이 프로젝트도 멈춤
- 포트폴리오는 `docker compose up` 한 번으로 독립 실행되어야 함

## 배운 점
- 다른 환경에서도 실행될 수 있도록 포트를 `.env`로 빼는 것을 검토 (기본값은 표준 포트)
- 외부 도구가 파일을 수정했다면 커밋 전 `git diff`로 직접 확인
