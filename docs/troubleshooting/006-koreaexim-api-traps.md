# 006. 수출입은행 API 도메인 변경·쉼표 문자열

- 날짜: 2026-11-05
- 관련: [ADR 0010](../adr/0010-exchange-rate-collection.md)

## 증상 / 함정
1. 인터넷 예제 대부분이 `www.koreaexim.go.kr` 주소를 사용
2. 매매기준율이 `"1,340.7"`처럼 쉼표가 포함된 문자열
3. 주말·공휴일·고시 전에는 빈 배열 `[]`
4. 오류는 HTTP 상태가 아닌 `result` 코드로 전달 (2=DATA코드, 3=인증, 4=일일 제한)

## 원인
- 요청 도메인이 `oapi.koreaexim.go.kr`로 변경(2025-06-25)되었고, 기존 도메인은 2026-04-30 종료 예정으로 공지됨
- 응답 형식이 화면 표시용 포맷을 그대로 사용

## 해결
- 신규 도메인 사용
- 쉼표 제거 후 `BigDecimal` 변환
- 빈 배열 → `Optional.empty()`, 최대 7일 거꾸로 조회
- `result != 1`이면 재시도하지 않는 영구 실패로 분류

## 보안
- 인증키는 `.env`로 분리, `spring.config.import`로 로드
- 요청 URL에 키가 포함되므로 URL을 로그·예외 메시지에 남기지 않음
- 설정 record의 `toString()`에서 키 마스킹

## 배운 점
외부 API는 블로그 예제보다 공식 공지를 먼저 확인한다.
