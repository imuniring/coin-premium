# 서비스 데이터 정책

현재 적용 중인 규칙만 모은 문서입니다. 규칙이 바뀌면 이 문서를 고치고, 바꾼 이유는 ADR로 남깁니다.
각 항목의 **근거**는 결정 배경을 담은 ADR입니다.

- 기준일: 2026-11-27 (2단계 진행 중)

## 1. 지원 코인
- 지원 코인과 거래소별 마켓 코드는 공통 계약 `CoinRegistry`가 기준입니다. 현재 BTC, ETH.
- 목록: `GET /v1/coins`, 상세: `GET /v1/coins/{symbol}` (`market`은 거래소 원래 코드)
- 지원 코인 추가·삭제는 배포로 반영합니다. 실행 중 수집 ON/OFF는 이후 Feature Flag로 제공 예정입니다.
- 근거: ADR 0025

## 2. 김프 계산
| 항목 | 기준 |
| --- | --- |
| 국내 가격 | Upbit 원화 마켓 (`KRW-{코인}`) 최신 체결가 |
| 해외 가격 | Binance USDT 마켓 (`{코인}USDT`) 최신 체결가 |
| 환율 | 한국수출입은행 USD/KRW 일환율 (5. 환율 참고) |
| 공식 | `(국내 가격 ÷ (해외 가격 × 환율) − 1) × 100` (%) |
| 자릿수 | 김프율 소수 4자리, 반올림(HALF_UP). 중간 비율은 소수 10자리 |

- USDT를 USD와 1:1로 보고 USD/KRW 환율을 적용합니다. 테더 기준 김프(Upbit USDT/KRW)는 2단계에서 추가 예정입니다.

## 3. 시간
- 저장과 API 응답은 모두 UTC입니다 (ISO-8601).
- 김프 추이의 일봉(`1d`)은 KST 자정 기준으로 나눕니다.
- 날짜가 필요한 판단(환율 적용일 등)은 한국 날짜(KST) 기준입니다.

## 4. 시세 신선도
국내·해외 시세 중 하나라도 체결 후 **60초**가 지나면 오래된 시세(stale)로 봅니다. 환율은 이 기준의 대상이 아닙니다.

| 상황 | 실시간 김프 API | 1분 스냅샷 저장 |
| --- | --- | --- |
| 정상 | 200, `stale: false` | 저장 (LIVE) |
| 시세가 60초 넘게 오래됨 | 200, `stale: true` (마지막 값, `tradedAt`으로 경과 시간 확인) | **저장하지 않음** → 공백 보정 대상 |
| 시세가 아예 없음 | 503 `MARKET_DATA_NOT_READY` (`missing`에 빠진 항목) | 건너뜀 |

- 화면에서 `stale: true`는 "지연" 등으로 표시하는 것을 권장합니다.
- 근거: ADR 0026

## 5. 환율
- 출처: 한국수출입은행 일환율. 수출입은행 안내상 영업일 11시 전후로 업데이트됩니다.
- 적용 기준: **고시일 D의 환율은 D 11:00 KST부터** 적용합니다. 그 전에는 직전 영업일 환율입니다.
- 주말·공휴일은 직전 영업일 환율을 유지합니다.
- 실시간 김프는 collector가 새 환율을 받은 시점부터 반영되므로, 11:00 직후 최대 약 30분은 전날 환율일 수 있습니다. 이력(공백 보정)은 위 적용 기준을 따릅니다.
- 근거: ADR 0010, ADR 0028

## 6. 김프 스냅샷 (이력)
- 매분 정각(UTC 기준 분 단위) 코인별 1개를 저장합니다. 같은 코인·같은 분은 하나뿐입니다.
- 출처(`source`)
  - `LIVE`: 그 분 정각에 실시간 시세로 저장
  - `BACKFILL`: 공백을 나중에 거래소 과거 1분 캔들로 채움
- 같은 분에 LIVE가 있으면 BACKFILL은 저장하지 않습니다 (실시간 값 우선).
- 근거: ADR 0012, ADR 0027

## 7. 공백 보정
- 10분마다(매 10분 30초) 최근 6시간에서 빈 분을 찾아 채웁니다. 최근 2분은 제외합니다.
- 분 m의 가격은 **시작 시각이 m-1분인 1분 캔들의 종가**입니다 (실시간의 "m 직전 최신 체결"과 같은 기준).
- m-1분 캔들이 없으면(그 1분 동안 체결 없음) 채우지 않고 비워 둡니다. 신선도 기준(60초)과 같은 규칙입니다.
- 환율은 5. 환율의 적용 기준을 따릅니다.
- BACKFILL의 체결 시각(`traded_at`)은 캔들 시작 시각입니다.
- 6시간보다 오래된 공백은 이후 일일 배치에서 점검합니다 (4단계 예정).
- 근거: ADR 0027

## 8. 김프 추이 API
`GET /v1/coins/{symbol}/premium/history?interval=&from=&to=`

| interval | 최대 조회 기간 | 최대 개수 |
| --- | --- | --- |
| `1m` | 1일 | 1,440 |
| `1h` | 31일 | 744 |
| `1d` (KST 자정 기준) | 366일 | 366 |

- `from`·`to`가 없으면 최근 1일을 조회합니다.
- 스냅샷(LIVE·BACKFILL)을 집계한 값입니다.
- 근거: ADR 0014

## 9. 에러 응답
모든 에러는 ProblemDetail 형식이며 `code`로 구분합니다.

| code | HTTP | 의미 |
| --- | --- | --- |
| `INVALID_SYMBOL` | 400 | 심볼 형식 오류 (영문 대문자·숫자 1~20자, 대소문자 무관하게 입력 가능) |
| `INVALID_INTERVAL` | 400 | 지원하지 않는 추이 간격 |
| `INVALID_RANGE` | 400 | 조회 기간 오류 (from ≥ to, 최대 기간 초과) |
| `INVALID_PARAMETER` | 400 | 그 밖의 파라미터 오류 |
| `UNSUPPORTED_SYMBOL` | 404 | 지원하지 않는 코인 |
| `MARKET_DATA_NOT_READY` | 503 | 시세·환율이 아직 없음 |

- 근거: ADR 0015
